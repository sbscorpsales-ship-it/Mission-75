APPLE HEALTH · IPHONE

Bring your real activity into GATIVX.

Safari cannot read Apple Health directly. This free, user-authorized Apple Shortcut sends today's measured step total and active energy to your GATIVX dashboard. No Apple Developer membership is needed for this web import.

Build the Shortcut once

  1. Find today's steps. Add the Shortcuts action Find Health Samples. Choose type Step Count, filter Start Date to Today, and turn off the result limit.
  2. Add the steps. Add Calculate Statistics, choose Sum, and use the Health Samples result. Keep its output as the Steps Total.
  3. Find today's active energy. Add another Find Health Samples, choose type Active Energy, filter Start Date to Today, and turn off the result limit.
  4. Add the energy. Add another Calculate Statistics action and choose Sum. This is active energy in kcal, not total daily calories.
  5. Format the date. Add Format Date for the current date and use the custom format yyyy-MM-dd.
  6. Open the import link. Add a Text action and insert the three calculated values as Shortcuts variables in this URL:
https://sbscorpsales-ship-it.github.io/Mission-75/app-v2.html?gativx_steps=[Steps Total]&gativx_active_energy=[Active Energy Total]&gativx_date=[Formatted Date]
  1. Add Open URLs and pass it the Text result. Run the Shortcut once and approve the requested Health access.

Make it refresh automatically

In Shortcuts, open Automation, create a Time of Day personal automation, choose how often it should run, select this Shortcut, and choose Run Immediately if iOS offers that option. You can also run the Shortcut manually whenever you want a fresh reading.

iOS controls when automations run. This is a scheduled import, not a continuous live HealthKit stream. You can run it more than once a day to refresh the totals.

What GATIVX records

  • Steps are labelled as Apple Health via Shortcuts.
  • Active energy is labelled separately from total daily calorie burn.
  • Native HealthKit readings take precedence over Shortcut readings.
  • Invalid or missing values remain blank; GATIVX does not invent zeroes or estimates.
  • Open the main GATIVX address above (not the alternate app-v2 page). If you are signed in to your existing GATIVX account there, the import can be backed up through your private account; otherwise it stays on this device until you sign in.

Health permissions are granted by you in iOS. GATIVX only receives the values you pass through the Shortcut URL.
